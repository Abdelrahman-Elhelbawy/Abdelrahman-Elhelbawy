## About Me

I'm a Backend Developer interested in building reliable, maintainable, and scalable software systems.

My focus is on backend engineering, API development, database design, software architecture, and the engineering practices that make applications easier to maintain and scale.

- **Backend Engineering:** C#, .NET, and ASP.NET Core
- **Architecture:** Clean Architecture, modular design, and separation of concerns
- **Data & Storage:** Relational databases, data modeling, and query optimization
- **System Reliability:** Transactions, idempotency, caching, and asynchronous processing
- **Engineering Practices:** Clean code, maintainability, and continuous learning

I believe good backend engineering is not just about making software work; it's about making it dependable, understandable, and ready to evolve.
